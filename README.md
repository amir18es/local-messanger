# Local Messenger Secure

Persian RTL team messenger built with Node.js, Express, Socket.IO, PostgreSQL, bcrypt, server-side sessions, and authenticated file access.

See **[README.fa.md](README.fa.md)** for the complete Persian setup guide, local VS Code steps, admin instructions, and deployment notes.

This project cannot be guaranteed 100% invulnerable and does not provide end-to-end encryption. Review `README.fa.md` security notes before production use.
